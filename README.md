# 📝 Blogicum — блоговая платформа

Blogicum — это учебная блог-платформа, созданная в рамках курса Яндекс.Практикума. 
Здесь можно писать и комментировать посты, сортировать их по категориям и указывать локации.

---

## 🔹 Возможности

✔ Создание постов с заголовками, текстом, категориями и местоположением.
✔ Просмотр и комментирование чужих записей.
✔ Фильтрация контента по категориям.
✔ Администрирование: управление пользователями, постами, категориями и комментариями.

---

## 🔧 Функционал

🔹 Регистрация и авторизация пользователей.  
🔹 Редактирование и удаление постов и комментариев.  
🔹 Прикрепление изображений к постам.  
🔹 Пагинация для удобного просмотра контента.  
🔹 Кастомные страницы ошибок (403, 404, 500).

## 🚀 Запуск проекта

1️⃣ **Склонировать репозиторий:**
```sh
git clone https://github.com/K-u-n-i-n/django_sprint4/
cd django_sprint4
```

2️⃣ **Создать виртуальное окружение:**
```sh
python3 -m venv venv
source venv/bin/activate  # Linux/MacOS
venv\Scripts\activate  # Windows
```

3️⃣ **Установить зависимости:**
```sh
pip install --upgrade pip
pip install -r requirements.txt
```

4️⃣ **Выполнить миграции:**
```sh
python manage.py migrate
```

5️⃣ **Запустить сервер:**
```sh
python manage.py runserver
```

---

## 📂 Тестовые данные

Файл `db.json` содержит готовые записи. Чтобы загрузить их в базу, выполните команду:
```sh
python manage.py loaddata db.json
```

Теперь можно зайти на сайт и протестировать его работу!
